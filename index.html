📖 คู่มือสำหรับมือใหม่

1. DR คืออะไร?

DR (Depositary Receipt) คือใบรับฝากที่ซื้อขายในตลาดหุ้นไทย แต่ราคาอิงหุ้นต่างประเทศ เช่น AAPL80 อิงหุ้น Apple ทำให้ซื้อหุ้นโลกด้วยเงินบาทได้ ราคา DR จึงขยับตามหุ้นแม่และค่าเงิน

2. อ่านการ์ดหุ้นอย่างไร?
  • Fair Value (ราคาที่ควรเป็น) = ราคาหุ้นแม่ × ค่าเงิน ÷ Ratio
  • ราคา SET = ราคาจริงของ DR บนกระดานไทยตอนนี้
  • โซนตั้งรับ = ราคาที่ถูกกว่า Fair Value อย่างน้อย 1 ช่วงราคา (Tick) ถ้าตั้งซื้อไม่เกินนี้ถือว่าได้ส่วนลด
  • ส่วนต่าง % ติดลบ (สีเขียว) = DR ถูกกว่าหุ้นแม่ / บวก (สีแดง) = DR แพงกว่า
3. ป้ายสถานะ 3 แบบ
  • 🟢 น่าสะสม — ราคา SET ต่ำกว่าหรือเท่าโซนตั้งรับ
  • ⚪ เหมาะสม — ใกล้เคียงราคาที่ควรเป็น
  • 🔴 แพงกว่าแม่ — จ่ายแพงกว่าซื้อหุ้นแม่ตรงๆ ควรรอ

⚠️ เป็นเครื่องมือช่วยเทียบราคาเท่านั้น ไม่ใช่คำแนะนำให้ซื้อขาย ควรศึกษาตัวธุรกิจและความเสี่ยงเอง

4. วิธีใช้งานแนะนำ
  1. ที่ 🏠 กระดานหลัก ค้นหาหรือกรองหุ้นที่สนใจ แล้วกดดาว ☆
  2. กดที่การ์ดเพื่อเปิดเครื่องคิดเลข ใส่งบเป็นบาท จะบอกว่าซื้อได้กี่หน่วย (รวมเศษ Odd Lot) และตั้งราคาเป้าหมาย/โน้ตของตัวเองได้
  3. ที่ ⭐ เริ่มวิเคราะห์ กด ⚡ อัปเดตราคาสด เฉพาะตอนที่ต้องการราคาล่าสุด
5. ทำไมราคาไม่ได้อัปเดตตลอดเวลา?

กระดานทั้งตลาดอัปเดตอัตโนมัติวันละ 2 รอบ เพื่อไม่ให้เกินโควตาฟรีของ Google ส่วนหุ้นที่ติดดาวกดอัปเดตสดได้เอง (ถ้ามีคนกดซ้ำภายใน 5 นาที ระบบจะใช้ราคาเดิม) ดูเวลาอัปเดตล่าสุดมุมขวาบนเสมอ
