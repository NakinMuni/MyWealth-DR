เข้าใจกลไกการทำงาน สูตรคำนวณ Fair Value และเกณฑ์ Tick Size ใหม่

1. ระบบทำงานแบบ 2 ความเร็ว (ทำไมต้องแยก "ตัวติดดาว" กับ "แคชทั้งตลาด")

เมื่อฐานข้อมูล DR มีจำนวนมาก (141 ถึง 400+ ตัว) การดึงราคาหุ้นต่างประเทศทั้งหมดพร้อมกันในคราวเดียวจะใช้เวลาราว 40–90 วินาที ซึ่งเกินขีดจำกัดการรอของหน้าเว็บ ระบบจึงถูกออกแบบแยกเป็น 2 ส่วน:

  • โหมดดึงสดตัวติดดาว (Starred Live Sync): เมื่อคุณกดรูปดาว ★ หน้าชื่อหุ้นที่ถือหรือเล็งไว้ แล้วกดปุ่ม อัปเดตสด (★) หน้าเว็บจะส่งเฉพาะรายชื่อกลุ่มนี้ไปดึงราคาหุ้นแม่, ราคาบน SET และค่าเงินแบบเรียลไทม์ ใช้เวลาเพียง 1.5 – 3 วินาที
  • โหมดสแกนทั้งตลาดเบื้องหลัง (Background Cache): Google Apps Script จะทยอยดึงข้อมูลครบทุกตัวในชีตให้อัตโนมัติทุกๆ 5–10 นาที (ตามเวลาที่คุณตั้งใน Trigger) แล้วเก็บลงแท็บซ่อน _CACHE_JSON ทำให้เปิดหน้าเว็บเมื่อไหร่ก็เห็นข้อมูลทั้งตลาดทันทีในไม่ถึง 0.5 วินาที

2. สูตรคำนวณ Fair Value และความหมายของป้ายสถานะ

Fair Value (บาท) = (ราคาหุ้นแม่ต่างประเทศ × อัตราแลกเปลี่ยน) ÷ Ratio
  • 🟢 น่าสะสม (Discount) : ราคาบนกระดาน SET ต่ำกว่าหรือเท่ากับ โซนตั้งรับ (Fair Value ลบ 1 Tick) หมายความว่าซื้อได้ถูกกว่ามูลค่าหุ้นแม่จริง (ค่า Prem/Disc ติดลบ)
  • ⚪ ราคาเหมาะสม (Fair) : ราคาบนกระดานอยู่ระหว่างโซนตั้งรับจนถึงราคา Fair Value พอดี เป็นราคายุติธรรมสำหรับทยอยสะสม
  • 🔴 แพงกว่าแม่ (Premium) : ราคาบนกระดานสูงกว่า Fair Value จริง หากไม่รีบควรตั้ง Bid รอในโซนสีเขียวแทนการเคาะขวา

3. เกณฑ์ช่วงราคา (Tick Size) ใหม่ของ SET (บังคับใช้ 16 พ.ย. 2569)

ระบบคำนวณโซนตั้งรับและการปุ่ม +/- 1 Tick ในเครื่องคิดเลขตามเกณฑ์ใหม่ของตลาดหลักทรัพย์ฯ แล้ว:

4. วิธีเพิ่ม DR ค่ายอื่นๆ ใน Google Sheets & ปักหมุดเป็นแอป

  • เพิ่มรายชื่อ DR ใหม่: พิมพ์ต่อท้ายในแท็บ DR โดยระบุให้ครบ 5 คอลัมน์ (DR | Ratio | ตลาดอ้างอิง | Ticker | Currency) เช่น ASML01 | 1:100 | Euronext | ASML.AS | EUR หรือ JEPI19 | 1:100 | NYSE | JEPI | USD
  • ระวังช่องว่างท้ายคำ: อย่าให้มีเว้นวรรคต่อท้ายชื่อ Ticker (ระบบจะตัดให้อัตโนมัติ แต่พิมพ์ให้ชิดจะดีที่สุด)
  • ใช้งานแบบแอปบนมือถือ: เปิดหน้านี้ผ่าน Chrome → กดปุ่ม ⋮ (มุมขวาบน) → เลือก เพิ่มลงในหน้าจอหลัก (Add to Home Screen)
